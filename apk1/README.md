# أمان للديون 🛡️

تطبيق ويب احترافي (PWA) لإدارة ديون العملاء اليومية، متجاوب بالكامل (Mobile First)، يدعم اللغة العربية RTL.

## المميزات
- تسجيل دخول / إنشاء حساب / نسيت كلمة المرور / تذكرني
- لوحة تحكم رئيسية بإحصائيات فورية
- إدارة عملاء كاملة (بطاقات، بحث، فرز، تصفية، صورة، عنوان، ملاحظات)
- ملف عميل تفصيلي مع كشف حساب قابل للطباعة
- إضافة ديون وتسجيل سدادات (جزئي/كامل) مع تحديث الرصيد تلقائيًا
- فواتير احترافية (58mm / 80mm) مع QR Code وBarcode وتوقيع، وتصدير PDF ومشاركة واتساب
- تقارير يومية/أسبوعية/شهرية/سنوية وحسب العميل والتاريخ، مع رسم بياني وتصدير PDF/Excel
- إعدادات: اسم النشاط، الشعار، العملة، الوضع الليلي، نسخ احتياطي واستعادة
- يعمل كتطبيق PWA قابل للتثبيت على الهاتف (Android/iOS) مع دعم عدم الاتصال

## ربط Firebase (لتفعيل المزامنة السحابية بين الأجهزة)
التطبيق يعمل مباشرة بدون أي إعداد باستخدام تخزين محلي (localStorage) على
نفس الجهاز. لتفعيل قاعدة بيانات سحابية حقيقية ومزامنة لحظية بين عدة
أجهزة في نفس الوقت:

1. أنشئ مشروعًا على [Firebase Console](https://console.firebase.google.com)
2. فعّل من القائمة الجانبية:
   - **Authentication** → Sign-in method → Email/Password
   - **Firestore Database** → إنشاء قاعدة بيانات (Production mode)
   - **Storage**
3. من إعدادات المشروع (⚙️ → Project settings) انسخ إعدادات تطبيق الويب (Web App Config)
4. افتح الملف `js/firebase.js` واستبدل القيم داخل `firebaseConfig` بالقيم الحقيقية
5. من تبويب Firestore → Rules، الصق القواعد الموجودة كتعليق في نهاية `js/firebase.js`

بمجرد حفظ إعداد حقيقي، سيكتشف التطبيق ذلك تلقائيًا ويتحول جميع
العمليات (عملاء، ديون، سدادات) للعمل عبر Firestore مع مزامنة لحظية
(onSnapshot) بين كل الأجهزة المسجّلة بنفس الحساب، دون الحاجة لتحديث الصفحة.

## تثبيت التطبيق كـ PWA
افتح التطبيق من متصفح Chrome على الهاتف → قائمة المتصفح ⋮ →
"إضافة إلى الشاشة الرئيسية" / "تثبيت التطبيق". سيعمل بعدها كتطبيق مستقل
بأيقونة خاصة وبدون شريط عنوان المتصفح.

## ملاحظات هامة
- كلمات المرور في الوضع المحلي (بدون Firebase) تُخزَّن بتجزئة بسيطة
  لأغراض التطوير فقط، وليست بديلاً عن نظام مصادقة حقيقي وآمن. يُنصح
  بشدة بربط Firebase Authentication قبل الاستخدام الفعلي مع بيانات حقيقية.
- الصور (شعار النشاط وصور العملاء) تُخزَّن كـ Base64 في الوضع المحلي؛
  عند ربط Firebase يُفضّل تطويرها لاحقًا لرفع الصور إلى Firebase Storage
  وتخزين الرابط فقط.
- تأكد من استبدال الأرقام والبيانات التجريبية ببيانات نشاطك الفعلي.
